# IB Project - Natation

## Descripción
Este proyecto es una colección de scripts en Python diseñados para realizar diversas tareas relacionadas con la natación. Incluye simulaciones, cálculos y funcionalidades específicas para videojuegos y análisis.

## Estructura del Proyecto
El proyecto contiene los siguientes archivos principales:

- **circuito.py**: Archivo principal para la simulación de circuitos relacionados con la natación.
- **esp_flecha.py**: Script para cálculos específicos de flechas en el contexto del proyecto.
- **if.py, if2.py, if3.py, if4.py, if5.py, if6.py**: Ejemplos y pruebas de estructuras condicionales.
- **main.py**: Archivo principal que centraliza la ejecución del proyecto.
- **requirements.txt**: Lista de dependencias necesarias para ejecutar el proyecto.
- **videojuego.py**: Script relacionado con la funcionalidad de videojuegos.
- **while.py, while1.py, while2.py, while3.py, while4.py**: Ejemplos y pruebas de estructuras de bucles.

## Requisitos

Para ejecutar este proyecto, necesitas tener instalado Python y las dependencias listadas en `requirements.txt`. Además, se recomienda usar un entorno virtual para aislar las dependencias.

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/AndersonStick/IB_project_natation.git
   ```

2. Navega al directorio del proyecto:
   ```bash
   cd IB_project_natation
   ```

3. Crea y activa un entorno virtual:
   ```bash
   python -m venv env
   source env/bin/activate # En Windows: env\Scripts\activate
   ```

4. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

## Uso

Ejecuta el archivo principal `main.py` para iniciar el proyecto:
```bash
python main.py
```
